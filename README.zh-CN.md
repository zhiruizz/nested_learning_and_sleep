# NL/Sleep Reproduction Lab

这是 Nested Learning 与 Language Models Need Sleep 的非官方、局部实现与诊断研究。
不是官方发布，没有复现全部架构或论文基准指标，没有机构背书。

安装与命令以 [英文 README](README.md) 为准。安装依赖后，可离线运行 CPU 合成时钟、
状态隔离、reset/activate、路由反例与数值测试，并从附带 CSV 重算历史汇总。
测试中小型 receiver 的更新只说明机制，不代表历史 3B 训练重演。

四类证据严格区分：CPU_MECHANISM_DEMO（合成机制）；BUNDLED_RESULTS_REANALYSIS
（已有聚合数值重算）；USER_SUPPLIED_ASSETS_REQUIRED（需合法自备资产）；
HISTORICAL_ONLY（关键私有状态不再分发，无法仅凭本包精确复演）。hash 不等于资产已提供。

原生模型最初五组各四条轨迹的平均准确率均为 25%，充分习得未建立。
后续六条 Teacher 完整习得门槛均失败。局部恢复与新旧取舍并存；Teacher 未学会的新能力
不能称被保留。小型探索性 dev 被重复使用，共享 Teacher、轨迹与配方不构成独立样本。

Llama 路径只在最后 MLP 增加两级 CMS，原骨干冻结；base 指 CMS base。
它是 CMS-inspired 扩展，不等于原生 HOPE。CACHE 约 3.40 倍只适用于特定重复 bank；
公开入口默认 REF，无可转移验收时拒绝显式加速请求，未知 scope 不扩大采用范围。
本轮 Llama/GPU 为 NOT_RUN。真正 64 边界、同时到期及终端生命周期仍未验证。

## 原生模型有界保留实验

[三 seed 合成任务报告](reports/native-retention-v1.md)：基础阶段旧映射和短复制均达到100%；新映射适应后，SFT/CMS旧映射均降至0，复制平均11.46%/10.87%。本次小模型、受限参数范围实验未显示分频更新的保护效果。协议、逐 seed 指标、成本和离线重算代码均已公开，与上游自然语言指标不能直接比较。


## 2026-11-05：真实 Llama 3.2-3B 对照结果

[完整报告](reports/agnews-retention-v2.md)：三种子、五组共15条运行已完成，主实验4752次SGD、288次Sleep更新、317.3秒。**三个正式起点均未通过预定旧任务学习门槛，不能据此宣称保留效果或Sleep优势。** 旧类/新类平均准确率分别为：SFT 0%/44.01%，CMS 0%/43.88%，显式0.5混合路由Sleep 0%/44.01%，额外有标签回放1.56%/43.75%。全部种子、检查点、负结果和额外评估开销均公开。

已定位并复现新接收专家在答案损失位置未被路由选中导致的零梯度，新增可选持久混合接收路径，并补齐教师/学生/在线模型的路由策略检查点与恢复守恒。默认自然路由不变；0.5混合属于明确的工程干预，并非论文完整复现。权重、原文与token数据包、私有检查点留在本地项目中。

## 合格起点与新隔离评估：v3

[完整报告](reports/agnews-qualified-v3.md)：三个种子的旧任务均通过预先冻结的训练／验证门槛，随后完成15组固定终点对照，并评估新的1024篇隔离文章。CMS+Sleep终点旧／新任务EM为0.00%／77.86%。报告保留全部种子、失败诊断、成本和中断恢复修订；该评估来自AG News训练划分，非外部独立确认，亦非完整论文复现。

## Sleep 无保留收益的探索性诊断

[诊断报告](reports/agnews-sleep-forensics-v3.md)：三个种子的前64步与原状态精确一致，旧验证EM在首次Sleep前已从92.45%降至0.39%，教师仅0.26%；864次独立自回归解码与原评分器一致。优先应在旧任务尚未遗忘时验证教师向接收器的转移，而非单纯加大晚期蒸馏预算。本轮未发现明确算子／评分错误，未改写v3结果或声称新的独立确认。

## 合格教师转移与高频 Sleep 开发对照

[v4 报告](reports/agnews-preupdate-v4.md)：三个种子在共同的 1,536 次更新预算下通过教师转移门槛，旧验证 EM 为 91.93% ± 1.97 个百分点。后续 18 条轨迹、90 个固定评估状态全部完成；高频“更新前/更新后教师”组终点旧 EM 均为 0，新 EM 分别为 32.68%/49.09%。额外金标回放得到旧 77.73%、新 40.76%，同时增加标签与计算。保留了较小转移预算的失败、单种子塌陷、成本和 CPU 预算失败记录。新的 1,024 篇隔离数据仍未评分；本次为验证集开发结果，不是独立确认或完整论文复现。常规 CPU 套件与两个较重的显式检查分别运行，256 次进程预算未放宽，见[协议说明](docs/agnews-preupdate-v4-protocol.md)。

## v5 机制诊断与冻结对照

[v5 完整对照](reports/agnews-anchored-v5.md)：21 个运行、126 个固定验证状态全部完成，无一通过旧新任务共同门槛。无 Sleep 旧/新 EM 为 0%/73.57%；冻结旧教师的 wake 回放为 75.13%/56.25%，加入本轮 Sleep 后两项均值更低。另行保留两套完整适配器并以训练标签拟合路由，得到 88.67%/71.48%；它增加状态存储、监督和两分支推理成本，不是 Sleep 收益，也未通过共同门槛。全部种子、失败、成本和来源锁均保留，预留评估数据仍未评分。

## V6：路由监督与成本匹配的重放对照

已完成 [v6 开发实验](reports/agnews-routing-fairness-v6.md)：分离旧上下文存档、阶段标签监督与路由选择的作用，验证共享骨干推理，并完成六组更新与前后向次数匹配的续训。新样本续训后，正确监督路由的旧／新 EM 为 88.67%／75.78%（联合门槛 2/3），打乱阶段标签后为 55.60%／36.59%。旧标签重放从已塌缩起点重新学习，联合门槛仅 1/3。完整保留所有种子、成本和失败记录；这些是有额外存储或监督的开发集探索，不能称为无标签 Sleep 成功或独立确认。
